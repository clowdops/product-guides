# Common

Pages in this section apply to **every ClowdOps product**. Your account, organisation, members, plan, and credit balance are shared — they do not change when you switch between [ClowdInfra](../cloud-agent/README.md) and [ClowdBI](../bi-agent/README.md).

| Guide | What it covers |
| --- | --- |
| [Account & Settings](settings.md) | Profile, security and MFA, organisation, members and roles, deployments, plan, billing and credits, the usage dashboard, and the activity log |
| [Approvals](approvals.md) | The queue where an unattended run defers an action to a person |
| [Connections](connections.md) | The external systems a project reaches, and what has been observed about each |
| [Contacts](contacts.md) | The contact registry: directory, lists, sharing posture, merges, knowledge review, and data-subject erasure |
| [Packs](packs.md) | Durable conventions, guidance and files published into agent sessions |
| [Signals](signals.md) | The attention queue: one record per condition, with a lifecycle and a signed dismissal |
| [Referrals](referrals.md) | Invite other teams with a referral code — both sides earn credit |
