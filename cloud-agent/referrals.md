# Referrals

**On this page:** [What it is](#what-it-is) · [Your referral codes](#your-referral-codes) · [Redeeming a code](#redeeming-a-code) · [How the reward qualifies](#how-the-reward-qualifies) · [Tracking your referrals](#tracking-your-referrals)

Invite other teams to ClowdOps and both sides earn credit. Referrals are a self-service growth program — every organisation can mint its own codes and share them.

---

## What it is

A referral connects two organisations: the **referrer** (you, sharing a code) and the **referred** org (a new team that signs up with it). When the referred org reaches a spend threshold, both sides receive a one-time credit grant to their PAYG balance.

| Side | Reward |
| --- | --- |
| **Referrer** (you) | A one-time credit when an org you referred qualifies |
| **Referred** (the new org) | A welcome credit, granted at the same moment |

> [!NOTE]
> Reward amounts and the qualifying threshold are set by the platform and shown live in the UI. They are journaled when a code is redeemed, so changing the program terms later never rewrites the reward already locked in for a past redemption.

---

## Your referral codes

Open **Settings → Referrals** to manage your codes. The page is available to every organisation.

From here you can:

- **Create a named code** — give it a label (for example `launch`, `conf-booth`, `partner-x`) so you can tell campaigns apart.
- **Activate / deactivate** a code — a deactivated code can no longer be redeemed, but redemptions already made still count.
- **Copy** a code or its shareable signup link (the link pre-fills the code on the signup form).

Share a code by sending the link directly, or have the invitee paste the code into the **Referral code** field on the ClowdOps signup page.

---

## Redeeming a code

A new organisation attributes itself to a referrer in one of two ways:

1. **At signup** — enter the code in the optional **Referral code** field on the registration form. A shared link of the form `…/signup?ref=CODE` pre-fills this automatically.
2. **After signup, before first purchase** — open **Settings → Referrals** and redeem a code there.

> [!IMPORTANT]
> A code can only be redeemed **before the org's first purchase**. Once an org has bought credits or a plan it can no longer attribute itself to a referrer.

---

## How the reward qualifies

Redeeming a code does not grant credit immediately — it records a *pending* redemption. The reward fires the first time the referred org's **cumulative completed spend** crosses the qualifying threshold. At that moment both the referrer reward and the referred welcome credit are granted, and the redemption is marked *qualified*.

This keeps the program honest: credit only changes hands once a referred org is genuinely using ClowdOps, not merely for signing up.

---

## Tracking your referrals

The **Settings → Referrals** page shows a live stats panel for the codes you own:

| Stat | Meaning |
| --- | --- |
| **Redemptions** | How many orgs have attributed themselves to your codes |
| **Qualified** | How many have crossed the spend threshold and triggered a reward |
| **Credits earned** | The total referrer credit granted to your balance so far |

Granted referrer credits land in your **PAYG bucket** and appear in your transaction history on the [Billing page](team-and-settings.md#billing).
